# leishmania_toolbox

This repo has the analysis code for the *Leishmania* toolbox manuscript. We use linear discriminant analysis (LDA) to classify sand flies as having taken a single bloodmeal or multiple bloodmeals, based on qPCR Ct values for the SHERP and HPB markers (normalised against ssrRNA). Models are trained and tested on two datasets: artificial-feeder infections and hamster infections. We compare accuracy, F1, precision and recall for SHERP + HPB, HPB alone and SHERP alone, and then apply the fitted models to field samples. The pipeline uses [`targets`](https://books.ropensci.org/targets/) and `tidymodels`. To run it, open `leishmania_toolbox.Rproj` and call `targets::tar_make()`. Raw data is in `data/`, helper functions are in `src/r/`, and the figures and metrics tables go to `outputs/`.
